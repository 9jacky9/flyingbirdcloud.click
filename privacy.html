隐私政策 (Privacy Policy)

FlyingBird机场（以下简称“我们”或“本平台”）高度重视并切实捍卫每一位用户的个人隐私与数字安全。本隐私政策旨在透明、详尽地向您说明我们在您使用加速服务期间对数据的处理方式。

一、 核心承诺：严格无日志原则 (Zero-Logs Policy)

我们郑重承诺：本平台绝不记录、收集、存储或共享任何用户的网络活动日志与真实通信数据。 具体包括但不限于：

  • 无浏览记录：我们从不记录您通过加速专线访问的任何网站网址、页面内容或搜索历史。
  • 无目标 IP 与 DNS 查询记录：我们不追踪您所请求的目标服务器真实 IP 地址，所有的 DNS 查询均在 RAM 内存中瞬时完成并在传输后立即丢弃。
  • 无通信数据包留存：所有流经中转服务器的数据均采用强抗审查高强度密文封装，服务器仅执行路由转发，不进行任何深度包检测（DPI）或数据还原。

二、 我们仅收集的最简必要运营数据

为了保证服务的正常计费、套餐分配及防范恶意滥用，我们仅在控制台处理最基础的账户运营信息：

  • 账户凭证：注册所需的有效电子邮箱地址（支持任意匿名邮箱）与单向哈希加密密码。
  • 套餐与流量计量：当前账户已购买的套餐类型、到期时间、当月剩余传输流量配额以及实时在线连接设备数。该数据仅为汇总总额，不包含任何具体的流量内容或访问行为明细。

三、 数据存储与加密机制

所有中转节点均采用只读 RAM 内存系统部署运行，系统不挂载持久化访问日志硬盘。即使服务器发生断电或意外故障，内存中的瞬时转发缓存将彻底清空，从物理硬件层面杜绝数据泄露可能。

四、 第三方服务与披露说明

我们绝不会将用户的任何账户信息向任何第三方商业机构、广告联盟出售或出租。在遵守法律法规的前提下，我们通过高标准的加密与匿名架构全力保护用户隐私。
